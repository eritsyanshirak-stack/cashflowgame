# Выход из круга

Мобильная финансовая настольная игра на чистом HTML/CSS/JavaScript.

## Автодеплой

После подключения репозитория к Vercel каждый push в `main` автоматически обновляет production-версию по той же ссылке.

## Запуск локально

Открой `index.html` в браузере или запусти простой статический сервер.

## Структура

- `index.html` — интерфейс
- `styles.css` — мобильный дизайн
- `game.js` — игровая логика
- `vercel.json` — статическая конфигурация Vercel
