# Выход из круга

Мобильная финансовая стратегия на React + TypeScript + Vite. Игровая логика отделена от интерфейса и изменяется только через типизированные команды.

## Balance v1.2

В тестовой ветке `balance-v1.1` экономика стала жёстче и реалистичнее:

- бизнесы проходят период раскрутки и не дают полную выручку сразу;
- у сделок есть уровень риска и проверка документов;
- встречаются редкие возможности, включая недвижимость ниже рынка;
- скрытые долги, проблемы с арендой, ремонтом и лицензиями могут остановить бизнес;
- нерешённая проблема может привести к принудительной продаже;
- банк отслеживает просрочки, реструктурирует долг и забирает залог;
- если залога не хватило, остаток долга остаётся у игрока;
- победа требует резерва, безопасного долга и трёх устойчивых месяцев.

Production не меняется до ручной проверки preview на iPhone.

## Автодеплой

После подключения репозитория к Vercel каждый push в `main` автоматически обновляет production-версию.

## Запуск локально

```bash
npm install
npm run dev
```

Проверки:

```bash
npm test
npm run lint
npm run build
```

## Структура

- `src/game` — доменная модель, движок, экономика, контент и сохранения
- `src/store` — состояние приложения
- `src/App.tsx` — React-интерфейс
- `docs/ARCHITECTURE.md` — границы модулей и инварианты
- `legacy` — предыдущий прототип без изменений
